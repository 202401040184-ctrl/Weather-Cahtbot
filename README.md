# 🌦️ Weather Chatbot

A simple weather chatbot website built using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Display current temperature
- Show weather conditions
- Display humidity and wind speed
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## How to Run
1. Download or clone this repository.
2. Open the index.html file in your browser.
3. Enter a city name to check its weather.

## Note
An OpenWeatherMap API key is required for weather data.
Do not share your private API key publicly.
